1. Project Overview & Objectives

EstateAI (House Predictor) is an enterprise-grade property valuation platform engineered for Project 3 of the QSkill Python Development Internship. Rather than relying on static heuristic calculators, the application embeds an active machine learning pipeline utilizing scikit-learn's Ordinary Least Squares Linear Regression.

Core Objectives:

  • Train a reproducible Linear Regression model on real estate transactions across key Indian tech hubs.
  • Eliminate data leakage via an end-to-end preprocessing pipeline combining numerical standardization and categorical one-hot encoding.
  • Provide auditable model metrics ($R^2$, MAE, MSE, RMSE) and interactive Actual vs. Predicted visualizations.
  • Store every single inference record in an encrypted SQLite database via SQLAlchemy with user-scoped isolation.

2. Mathematical Foundations of Linear Regression

Multiple Linear Regression models the relationship between a continuous dependent variable $y$ (property price) and an explanatory feature vector $\mathbf{x} = [x_1, x_2, \dots, x_p]^T$:

$$\hat{y} = \beta_0 + \sum_{j=1}^{p} \beta_j x_j + \epsilon$$

Where $\beta_0$ represents the base valuation intercept, $\beta_j$ represents the marginal contribution of the $j$-th feature, and $\epsilon \sim \mathcal{N}(0, \sigma^2)$ is the Gaussian noise term.

Ordinary Least Squares (OLS) Closed-Form Solution:

$$\mathbf{\beta} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$

scikit-learn optimizes this using LAPACK driver routines (singular value decomposition / QR decomposition) for guaranteed numerical stability and sub-millisecond evaluation.

3. Preprocessing & Feature Engineering

The preprocessing pipeline (ml/preprocess.py) ensures that training transformations are saved to models/preprocessor.pkl and reused identically during live web inference:

1. Numerical Features: Features: Area, Bedrooms, Bathrooms, Floors, Parking.

Transformed via StandardScaler: $z = \frac{x - \mu}{\sigma}$, giving zero mean and unit variance.

2. Categorical Features: Features: Location, Main Road, Furnishing, Amenities.

Transformed via OneHotEncoder(handle_unknown='ignore') to prevent arbitrary numerical ordering.

4. Evaluation Metrics Guide

Coefficient of Determination ($R^2$)

$$R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$

Measures the proportion of total variance explained by the model compared to a baseline mean predictor.

Mean Absolute Error (MAE)

$$\text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$$

The average magnitude of absolute residuals in the target unit (INR ₹). Highly robust to extreme outliers.

Root Mean Squared Error (RMSE)

$$\text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2}$$

The quadratic scoring rule that penalizes larger errors. Crucial for financial investment risk assessment.
